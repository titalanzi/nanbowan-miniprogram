# 南波万飞盘 - 功能清单

## 一、用户管理

| 功能 | 说明 |
|------|------|
| 用户注册 | 输入昵称、选择性别、上传头像完成注册，自动获取 OpenID |
| 个人资料编辑 | 修改昵称、头像、性别，同步更新所有已创建比赛的发起人信息 |
| 主理人助理认证 | 输入验证码升级为主理人助理，获得更多管理权限 |
| 用户云端同步 | 自动与云端同步用户数据，支持缓存清除后恢复 |
| 性别补填提醒 | 已注册但未填写性别的用户，自动弹出编辑弹窗补填 |

## 二、比赛管理

### 2.1 创建比赛（手动模式）

| 功能 | 说明 |
|------|------|
| 基本信息 | 填写比赛名称、地点、日期 |
| 队伍管理 | 添加/编辑/删除队伍，设置队伍名称和颜色 |
| 球员管理 | 为每支队伍添加/删除球员，设置姓名和性别 |
| 统计项管理 | 默认4项（得分/助攻/D盘/烂盘），可自定义添加统计项和颜色 |
| 防重复提交 | 创建中禁用按钮，显示加载遮罩 |

### 2.2 创建比赛（随机分配模式）

| 功能 | 说明 |
|------|------|
| 录入参赛队员 | 手动添加队员（姓名+性别），支持导入取伙名单 |
| 导入取伙名单 | 从 Excel 文件导入队员信息，支持预览和编辑 |
| 创建队伍配置 | 设置队伍名称、颜色、队长、固定成员 |
| 随机分配 | 按男女均衡原则随机分配队员到各队伍 |
| 点击调整 | 先点击选中队员，再点击目标队伍完成移动 |
| 队长自动取消 | 队长被移到其他队伍时自动取消队长身份 |

### 2.3 比赛记录（进行中）

| 功能 | 说明 |
|------|------|
| 选择队伍和球员 | 点击选择当前队伍和球员 |
| 记录统计 | 点击统计项按钮（得分/助攻/D盘/烂盘）记录数据 |
| 撤销记录 | 撤销最近一条记录 |
| 删除记录 | 删除指定记录 |
| 分组图片下载 | Canvas 绘制分组图片并保存到相册 |
| 羁绊系统 | 根据比赛成员自动触发羁绊，点击查看详情 |
| 结束比赛 | 确认结束比赛，自动跳转到比赛详情页 |
| 权限控制 | 仅比赛创建者或主理人助理可编辑 |

### 2.4 比赛详情（已结束）

| 功能 | 说明 |
|------|------|
| 队伍比分 | 展示各队伍得分、助攻、D盘统计 |
| 队伍详情 | 查看队伍内每位球员的详细数据 |
| 数据排行榜 | 按统计项切换查看排行榜（得分/助攻/D盘/烂盘） |
| MVP 排行榜 | 综合评分（得分+助攻+D盘-烂盘）排名，支持并列 |
| 飞盘精神排名 | 基于点赞/踩的分数排名，仅显示正分队员 |
| 点赞/踩 | 每人每场比赛对每位队员只能给1个赞或1个踩 |
| 羁绊系统 | 触发并展示羁绊效果，点击查看详情 |
| MVP 截图分享 | 自动生成 MVP 排行榜图片用于转发分享 |
| 恢复比赛 | 主理人助理可将已结束比赛恢复为进行中 |
| 删除比赛 | 主理人助理可删除比赛 |
| 编辑分组 | 比赛进行中可编辑队伍和成员 |

### 2.5 编辑分组

| 功能 | 说明 |
|------|------|
| 添加/编辑/删除队伍 | 管理比赛中的队伍 |
| 添加/删除成员 | 管理队伍中的球员 |
| 成员移动 | 点击选中队员后点击目标队伍完成移动 |

## 三、队训管理

### 3.1 创建队训

| 功能 | 说明 |
|------|------|
| 基本信息 | 填写标题、日期、开始/结束时间、地点、描述 |
| 分组配置 | 创建分组（名称），支持多个分组 |
| 防重复提交 | 提交中禁用按钮，显示加载遮罩 |
| 自动生成二维码 | 创建成功后自动生成签到二维码 |

### 3.2 队训详情

| 功能 | 说明 |
|------|------|
| 报名参加 | 选择分组加入队训，或以教练身份加入 |
| 签到 | 扫码签到参加队训 |
| 个人资料完善 | 未完善资料的用户弹窗提示补填 |
| 分组展示 | 按分组展示参加者，含性别图标和人数统计 |
| 评分入口 | 队长和教练可进入评分页面 |
| 互评入口 | 参加者可对队友进行文字互评 |
| 管理入口 | 创建者/主理人助理可进入管理页面 |
| 结束队训 | 创建者/主理人助理可结束队训 |
| 分享邀请 | 支持微信转发邀请他人参加 |

### 3.3 队训评分

| 功能 | 说明 |
|------|------|
| 队长评分 | 队长对本组队员评分（传盘成功率、接盘稳定性、防守执行率） |
| 教练评分 | 教练对分组整体评分（传盘选择、进攻/防守战术执行度等） |
| 评分维度 | 支持多维度评分（2/4/6/8/10分制） |
| 雷达图展示 | 以雷达图展示各维度评分 |
| 训练前后均可评分 | 训练结束前可开始评分，结束后可修改评分 |
| 权限验证 | 双重验证队长身份（captains数组 + isCaptain字段） |

### 3.4 队友互评

| 功能 | 说明 |
|------|------|
| 文字评语 | 对除自己以外的队友撰写文字评语 |
| 批量提交 | 一次性提交所有评语 |
| 过滤自己 | 自动过滤掉当前用户，不展示自我评价 |

### 3.5 队训管理

| 功能 | 说明 |
|------|------|
| 成员管理 | 查看所有参加者，按分组展示 |
| 设置队长 | 将参加者设为队长（支持多队长） |
| 取消队长 | 取消参加者的队长身份 |
| 设置教练 | 将参加者设为教练 |
| 取消教练 | 取消参加者的教练身份 |
| 移动分组 | 将参加者移动到其他分组 |
| 移除参加者 | 将参加者从队训中移除 |

### 3.6 我的队训

| 功能 | 说明 |
|------|------|
| 队训列表 | 查看自己参加的所有队训 |
| 综合雷达图 | 聚合所有队训评分数据，展示综合雷达图 |
| 综合评分 | 计算所有队训的平均评分 |

## 四、首页与导航

### 4.1 活动页（首页）

| 功能 | 说明 |
|------|------|
| 进行中活动 | 展示所有进行中的比赛和队训 |
| Banner 轮播 | 从云存储加载轮播图，支持本地缓存 |
| 下拉刷新 | 支持下拉刷新活动列表 |
| 快捷入口 | 创建比赛、创建队训、我的比赛、我的队训 |
| 飞盘知识入口 | 飞盘词汇、飞盘规则快捷入口 |

### 4.2 赛程记录页

| 功能 | 说明 |
|------|------|
| 历史比赛 | 展示已结束的比赛列表 |
| 历史队训 | 展示已结束的队训列表 |
| Tab 切换 | 比赛和队训切换展示 |

### 4.3 我的比赛

| 功能 | 说明 |
|------|------|
| 我创建的比赛 | 展示当前用户创建的所有比赛 |
| 按时间排序 | 最新创建的比赛排在前面 |

## 五、飞盘知识

### 5.1 飞盘词汇

| 功能 | 说明 |
|------|------|
| 字母分组 | 按英文字母分组展示飞盘术语 |
| 右侧字母索引 | 快速跳转到对应字母分组 |
| 关键词搜索 | 支持中英文关键词搜索 |
| 英文发音 | 点击词汇播放 TTS 英文发音（云函数合成） |
| 词汇说明 | 点击查看词汇详细说明弹窗 |
| 分享 | 支持转发到聊天和朋友圈 |

### 5.2 飞盘规则

| 功能 | 说明 |
|------|------|
| 章节展示 | 按章节展示完整飞盘规则 |
| 目录导航 | 侧边目录快速跳转到对应章节 |
| 关键词搜索 | 支持搜索规则条文、名词定义 |
| 滚动联动 | 滚动时自动高亮当前章节 |
| 分享 | 支持转发到聊天和朋友圈 |

## 六、特色功能

### 6.1 羁绊系统

| 功能 | 说明 |
|------|------|
| 羁绊触发 | 根据比赛成员自动检测并触发羁绊效果 |
| 羁绊详情 | 点击羁绊标签查看名称、描述和图片 |
| 图片懒加载 | 点击后才从云存储获取羁绊图片 |
| 四驱兄弟 | 特殊羁绊：结束比赛时自动移除羁绊成员的烂盘记录 |

### 6.2 特殊成员标识

| 功能 | 说明 |
|------|------|
| 特殊名字图标 | 指定成员名字旁显示 no1 图标 |
| 橙色名字高亮 | 特定成员在排行榜中以橙色显示 |

### 6.3 性别标识

| 功能 | 说明 |
|------|------|
| 性别图标 | 分组中显示男女数量图标 |
| 头像边框 | 男性蓝色、女性粉色、未知灰色 |
