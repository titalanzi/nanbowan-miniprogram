# 南波万飞盘

> 一款面向飞盘社群的微信小程序：轻松组织比赛、按实力均衡分队、实时记分、自动出 MVP 与飞盘精神榜，还附带队训管理、可视化战术板、飞盘知识库等一整套社群运营工具。

## 📱 这是什么

「南波万飞盘」是给飞盘俱乐部 / 主理人 / 普通玩家用的微信小程序。它解决的核心问题是：

- 一场飞盘局，十几二十个人怎么**公平分队**？
- 比赛进行中怎么**快速记比分、助攻、D 盘、烂盘**？
- 打完怎么**自动排 MVP、出精神榜、生成分享图**？

从创建比赛、随机分队、现场记分到赛后榜单，全流程在小程序里闭环，数据云端同步、换手机也不丢。

---

## ✨ 核心亮点

- **按实力等级分队**：导入名单可标注每位队员实力等级（1 = 最强），系统分层均衡分配到各队，保证强弱搭配公平；恰好 4 名 1 级队员时一键自动建 A/B/C/D 四队并各设队长。
- **Excel 一键导入**：支持从 Excel 导入取伙名单，预览、编辑、补填性别与等级。
- **实时记分 + 撤销**：比赛进行中点按记录得分 / 助攻 / D 盘 / 烂盘，误点可撤销。
- **自动榜单**：MVP 排行榜（得分 + 3×助攻 + 2×D 盘 − 2×烂盘）、各单项榜、飞盘精神榜，赛后自动生成可转发截图。
- **羁绊系统**：根据同场成员自动触发趣味羁绊彩蛋。
- **队训管理**：创建队训、扫码签到、队长 / 教练多维度评分、雷达图、队友互评、综合成长雷达。
- **飞盘战术板**：可视化拖拽画布摆放攻防双方与飞盘，多步骤时间轴分镜演示跑位，支持分段 / 全部播放、每页文字解说、撤销重做，并可一键分享给队友。
- **飞盘知识库**：飞盘术语（含 TTS 英文发音）、完整规则，可搜索可分享。

## 🧩 功能一览

### 比赛管理
- 创建比赛（名称 / 地点 / 日期）
- 手动建队 / 随机分配两种模式
- 随机分配：录入或导入队员 → 设置队伍（名称、颜色、队长、固定成员）→ 均衡分队 → 手动微调
- 编辑分组：增删队伍、成员移动、队长自动取消

### 比赛记录（进行中）
- 选队伍、选球员、点按记录统计项
- 撤销 / 删除记录
- 分组图保存相册、羁绊触发、结束比赛
- 权限：仅创建者或主理人助理可编辑

### 比赛详情（已结束）
- 队伍比分与队员明细
- MVP 榜、单项榜、飞盘精神榜
- 点赞 / 踩、MVP 截图分享、恢复 / 删除比赛

### 队训管理
- 创建队训（自动生成签到二维码）
- 报名 / 扫码签到 / 微信分享邀请
- 队长与教练多维度评分 + 雷达图
- 队友文字互评
- 我的队训：综合雷达图与平均评分

### 飞盘战术板
- 可视化拖拽画布：从道具栏拖出**蓝方 / 红方队员**与**飞盘**到球场，自由摆放攻防站位；拖回删除区即可移除
- **多步骤时间轴**：支持「加页 / 删页」构建分镜，逐页演示战术跑位与传递路线；点击节点可跳转到任意一步
- **播放演示**：分段播放 / 播放全部，播放时浮窗显示当前页文字解说，方便训练时讲解
- **每页解说**：每个站位步骤可写不超过 200 字描述，播放时同步展示
- **撤销 / 重做**：误拖错放可快速回退或前进
- **自动保存 + 云端同步**：编辑即存，数据存于微信云开发（云函数 `saveTactic` / `getTactic` / `getTacticList` / `deleteTactic`），换设备不丢
- **一键分享**：可直接转发给队友；对方从分享链接打开即进入**只读查看模式**，无需登录即可看战术
- 列表页管理：所有已保存战术板一览（名称 / 步数 / 人数 / 更新时间），支持分享与删除

### 首页与导航
- 进行中活动聚合、Banner 轮播、下拉刷新
- 历史赛程、我的比赛 / 我的队训快捷入口
- 飞盘词汇（TTS 发音）、飞盘规则（目录导航 + 搜索）

### 特色功能
- **羁绊系统**：成员组合触发彩蛋，部分羁绊影响计分（如「四驱兄弟」赛后移除烂盘）
- **特殊成员标识**：特定成员名字橙色高亮
- **性别标识**：男性蓝、女性粉、未知灰的头像边框与图标

## 🚀 快速开始（开发者）

> ⚠️ 小程序需通过**微信开发者工具**运行，无法直接 `npm start`。部署涉及云开发环境，请按以下步骤：

1. **克隆仓库**
   ```bash
   git clone https://github.com/titalanzi/nanbowan-miniprogram.git
   cd nanbowan-miniprogram
   ```

2. **用微信开发者工具打开**
   打开项目根目录，工具会自动识别 `project.config.json`。

3. **构建 npm**
   工具菜单 → **工具 → 构建 npm**（已依赖 TDesign，构建后生成 `miniprogram_npm/`，无需手动安装）。

4. **开通云开发**
   在开发者工具中开通云开发环境，记录你的环境 ID。

5. **部署云函数**
   右键 `cloudfunctions/` 下各函数目录 → **上传并部署：云端安装依赖**（主要函数：`syncMatch`、`getMatchesFromCloud`、`syncUser`、`createTraining`、`submitScores`、`tts`、`saveTactic` / `getTactic` / `getTacticList` / `deleteTactic`（战术板）等）。

6. **编译预览**
   点击编译，使用微信扫码预览。

## 📂 目录结构

```
nanbowan-miniprogram/
├── pages/                 # 主包页面（首页/创建比赛/比赛详情/记录/排行榜/个人中心…）
├── packageA/              # 分包：比赛核心流程（create-match、match-record、edit-groups…）
├── packageB/              # 分包：队训、飞盘知识等
├── cloudfunctions/        # 云函数（同步/查询/评分/签到/TTS 等）
├── components/            # 自定义组件
├── images/                # 图片资源（性别图标、排名图标等）
├── utils/                 # 工具函数（storage、cloud、随机分队、Excel 解析）
├── app.js / app.json / app.wxss   # 小程序入口与全局配置
└── project.config.json    # 项目配置
```
